# JS Landscaping: answer this post

A button for Chrome. You are looking at a post in a group. Press the button, or Alt+Shift+J. The app opens in a new tab with the post's words and the group already on it, reads it, and writes the comment. You copy it and paste it yourself.

It does not scroll, post, or read anything except the page you are on, and only when you press the button. That keeps it inside Facebook's rules and keeps your account safe.

## Install

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** (top right).
3. Press **Load unpacked** and choose this `extension` folder.
4. Pin it from the puzzle-piece menu so the button stays on the toolbar.

You need to be signed in to the app in the same browser. The button uses your signed-in session and nothing else.

## Getting the best reading

Select the post's text before pressing the button and that is exactly what is sent. With nothing selected it takes the post nearest the middle of the window. Either way the form shows what it read, so a wrong group name is a glance and a fix.
